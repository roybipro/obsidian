# Phase 18 - Bit Manipulation

**Goal:** Use XOR, AND, and shifts to save space and time.

## Core patterns
- XOR cancels duplicates (single number)
- n & (n - 1) clears the lowest set bit
- Shifts to read or build bits
- Addition with XOR and carry using AND
